# Pyromi – Marketing Website

The marketing website for **Pyromi**, an AI video editor that builds edits directly on the user's timeline.

🔗 **Live site:** [pyromi-launchpad.vercel.app](https://pyromi-launchpad.vercel.app)

## Highlights

- Landing page with a hero video, audience sections (creators, editors, video teams) and product proof
- "Made with Pyromi" output carousel that auto-scrolls and pauses on hover
- Media served from the repository without Git LFS so Vercel builds deploy cleanly
- Responsive layout and consistent ambient styling across sections

## Tech stack

- React and TypeScript
- Vite
- Tailwind CSS with shadcn/ui components
- Deployed on Vercel

## Getting started

```bash
git clone https://github.com/Abdullah-saggaf/pyromi-launchpad.git
cd pyromi-launchpad
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).
